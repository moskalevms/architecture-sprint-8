### Запуск проекта

Для запуска проекта выполнить команду docker-compose up -d --build

### Состав проекта и эндпойнты

Проект состоит из провайдера аутентификации Keycloak, доступного по адресу http://localhost:8080
UI проекта доступен по адресу http://localhost:3000
Бэкенд часть проекта доступна по адресу http://localhost:8070

### Проверка функциональности

После запуска проекта, открыть в браузере веб-приложение по адресу http://localhost:3000. Откроется страница логина.
В форме ввода логина и пароля ввести логин - prothetic1, пароль - prothetic123.
Откроется страница для скачивания отчетов. Нажать Скачать отчет - пользователю будет доступен отчет.

Перезапустить приложение и в форме ввода логина и пароля ввести логин - user1, пароль - password123.
На форме для скачивания отчетов нажать на кнопку Скачать отчет. Получить ошибку HTTP error! status: 403.
